# Future

Hobby project first. Built so it can serve real users (~1k+) on one server.

## Scale assumptions

| Area | Expectation |
| --- | --- |
| Users | ~1k+ |
| Servers | One app server is enough for V1–V2 |
| Bottlenecks | Video upload; later AI latency |
| UX | Clarity first — users leave if the path is confusing |

## Monetization (later)

- Instagram-led growth
- Paid 1:1 coaching / form feedback
- AI form coaching (main paid tier)
- Optional gear sales / delivery

## Product direction (high level)

| Phase | Focus |
| --- | --- |
| Skill tracker | Path, assessment, workouts, progress |
| Intelligent coach | AI verify, recommendations, form score |
| Social | Leaderboard, friends, feed, challenges |
| Platform | Coaching marketplace, gear |

Detail and timing: [../02-requirements/roadmap.md](../02-requirements/roadmap.md).

## Competitor

[calitracker.com](https://calitracker.com/) — track skills and progress. CaliTrack differentiates with a prerequisite graph, strict video proof, and (later) AI coaching on the same path.
