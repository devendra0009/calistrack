# CalisTrack web (React 19 + Vite)

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```

App: http://localhost:5173  
API: `VITE_API_BASE_URL` (default `http://localhost:8084`)

## Scripts

- `npm run dev` — Vite + React Compiler
- `npm run build` — typecheck + production bundle
- `npm run preview` — preview production build
